### What I learned

I learned how to center a component right in the middle of the page using flexbox.

This is shown in the code below:

```html
<div class="container">
  <div>
    Some box
  </div>
</div>
```
```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 95vh;
}
```
